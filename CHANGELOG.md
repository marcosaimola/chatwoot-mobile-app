# Changelog

## [4.4.0] - 2025-01-17

### ✨ New Features
- **Kanban Integration**: Added funnel item management system
  - View linked funnel items in conversations
  - Add new funnel items with contact name pre-filled
  - Edit existing funnel items
  - Delete funnel items with confirmation dialog
  - Display funnel stage and value in badge format
  - Support for multiple funnels and stages via dropdowns

### 🌐 Internationalization
- **Multi-language Support**: All Kanban features now support multiple languages
  - English translations
  - Portuguese (Brazil) translations
  - Consistent with existing app language system

### 🎨 UI/UX Improvements
- **Custom Branding**: Updated app configuration for Zapicrm
  - Changed default URL to `atendimento.zapicrm.com.br`
  - Updated app bundle ID to `br.com.zapicrm`
  - Custom help center integration
  - Removed SSO login option
  - Updated notification icons

### 🔧 Technical Improvements
- **Background Audio**: Audio messages now continue playing when device is locked
- **API Integration**: New webhook service for custom API endpoints
- **Error Handling**: Improved error handling and user feedback
- **Performance**: Optimized component rendering and state management

### 🐛 Bug Fixes
- Fixed duplicate API calls issue
- Resolved button layout and spacing issues
- Fixed contact name pre-filling in forms
- Improved form validation and error messages

### 📱 Platform Support
- **iOS**: Full support with background audio capabilities
- **Android**: Full support with media playback permissions
- **Firebase**: Integrated push notifications and analytics
